# Anexos

Diretório configurado para anexos do Obsidian. Organize por tipo:

- `Diagramas/` — SVG/PNG exportados de diagramas técnicos.
- `Capturas/` — screenshots sanitizados, sem dados pessoais ou tokens.
- `Exportações/` — artefatos documentais permitidos, nunca pacotes de app ou
  cópias de provas sem autorização.

Não armazenar provas brutas, PDFs de corpus, arquivos `.env`, chaves, dumps de
banco, logs com respostas/conteúdo de usuários ou dados que não sejam necessários.
Quando a licença de um anexo for incerta, não copie para cá.
