# Visão do Produto

## Nome

**Solucionar** é o nome de trabalho proposto pelo responsável para a próxima
versão do produto. A marca final, a disponibilidade e eventuais conflitos não
foram verificados. O código e os identificadores atuais continuam como Prova
Social até uma decisão e um plano de migração explícitos.

## Intenção

Prova Social é uma rede de questões e provas: encontrar, importar, organizar,
resolver, revisar e discutir provas. O objeto principal é a questão, não um
feed genérico. O ciclo de valor é:

**Descobrir → Salvar → Fazer → Errar → Entender → Discutir → Melhorar → Refazer**

## Proposta de valor

> Encontre ou importe uma prova, resolva no seu ritmo e descubra exatamente o
> que precisa estudar.

Uma capacidade essencial pretendida é criar uma tentativa nova composta por
questões erradas para conferir a aprendizagem após revisão. A disponibilidade
real está registrada em [[../00 - Central/Estado Atual|estado atual]].
