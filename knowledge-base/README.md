nenhum plugin da comunidade, sem snippets ou scripts personalizados. Não há
segredos neste vault. A configuração `.obsidian` não substitui controles de
acesso nem proteção do repositório.

## Hierarquia e precedência

1. `AGENTS.md` é a fonte normativa.
