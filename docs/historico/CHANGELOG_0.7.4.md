# Prova Social 0.7.4

## Questões e provas

- Revisão de resultados virtualizada com filtros úteis e imagens originais nas
  páginas públicas de questões.
- Busca e catálogo mais fáceis de percorrer, com filtros e estados vazios
  explícitos.
- Importação de PDF protegida contra documentos acima do limite de páginas,
  com descarte seguro dos recursos nativos.
- Melhorias de retomada offline, publicação de imagens e sincronização de
  tentativas.

## Web e distribuição

- Landing page com metadados para buscadores e páginas HTML canônicas para
  provas e questões públicas, sem expor gabaritos.
- APKs de release distribuídos por arquitetura; o Flutter Web continua
  publicado pelo pipeline Cloudflare Pages.
- Refinamentos visuais, responsivos e de acessibilidade nas telas do app.
